CM GROUP MINI APP — БЫСТРЫЙ ЗАПУСК НА REG.RU

1. Загрузите ВСЕ файлы и папку api в корень сайта app.cmgroup.pro.
2. Убедитесь, что index.html лежит непосредственно в корне.
3. Скопируйте api/config.example.php в api/config.local.php.
4. В config.local.php вставьте токен бота из @BotFather.
5. Проверьте адрес https://app.cmgroup.pro/api/health.php — поле ok должно быть true.
6. Открывайте приложение из inline-кнопки Web App или Menu Button бота.
7. Для автоматической отправки данных в SaleBot добавьте его webhook URL в event_webhook_url.

Подробные инструкции: README.md, REG_RU_SETUP.md, BOT_INTEGRATION.md.

# Публикация CM Group Mini App на REG.RU

## Требования

- поддомен `app.cmgroup.pro` направлен A-записью на IP хостинга;
- сайт `app.cmgroup.pro` создан в ispmanager;
- SSL Let's Encrypt подключён;
- PHP 8.1 или новее.

## Загрузка

1. Откройте в ispmanager: **Сайты → app.cmgroup.pro → Файлы сайта**.
2. Удалите стандартный `index.html`.
3. Загрузите все файлы репозитория в корневую папку сайта.
4. В корне должны находиться:

```text
index.html
app.js
styles.css
logo.png
.htaccess
api/
```

## Серверная конфигурация

1. В папке `api` создайте копию `config.example.php`.
2. Назовите копию `config.local.php`.
3. Откройте её и вставьте токен бота:

```php
'bot_token' => '123456789:ВАШ_ТОКЕН',
```

4. Проверьте:

```php
'allowed_origin' => 'https://app.cmgroup.pro',
```

5. Для папки `api/storage` установите права записи владельцу. Обычно достаточно `700` или `750`; не ставьте `777`, если это не потребовала поддержка REG.RU.

## Проверка

Откройте:

```text
https://app.cmgroup.pro/api/health.php
```

Ожидается `"ok": true`.

Затем откройте приложение из Telegram. В верхней части должен появиться статус **«Сохранено»**. В обычном браузере будет статус **«Только на устройстве»** — это нормально, поскольку браузер не передаёт Telegram-авторизацию.

## Проверка синхронизации

1. Откройте Mini App на телефоне.
2. Пройдите квиз, укажите имя и телефон.
3. Закройте приложение.
4. Откройте его с другого устройства под тем же Telegram-аккаунтом.
5. Должны восстановиться имя, телефон, результат, материалы и последний экран.

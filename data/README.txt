ПОСТОЯННЫЕ ДАННЫЕ CM GROUP MINI APP

Эту папку нельзя удалять или заменять при обновлении приложения.

После запуска здесь автоматически создаются:
- profiles/ — отдельный JSON-файл профиля для каждого Telegram-пользователя;
- events/ — отдельный JSONL-журнал событий для каждого Telegram-пользователя.

Имена файлов — SHA-256-хэши Telegram ID. Прямой доступ из браузера запрещён файлом .htaccess.

Перед обновлением приложения сделайте резервную копию всей папки data.
При загрузке новой версии заменяйте код приложения, но сохраняйте существующую папку data целиком.

# CM Group Mini App

Telegram Mini App для диагностики пользователя, персонального кабинета, материалов CM Group и сбора лидов.

## Что реализовано

- квиз из 5 вопросов и персональная рекомендация;
- сохранение имени, телефона, ответов квиза, результата и статуса доступа;
- восстановление профиля на другом устройстве по подтверждённому Telegram ID;
- локальное сохранение как резерв при временной недоступности сервера;
- базовый курс из 5 видеоуроков;
- книга, дополнительные уроки, продукты CM Signals / CM Lab / QUICK START;
- финансовый калькулятор;
- обязательный запрос телефона перед защищёнными материалами;
- журнал событий приложения;
- подготовленный HTTPS webhook для SaleBot/CRM;
- корректный возврат в `@cmgroup_pro_bot`;
- проверка подлинности Telegram `initData` на сервере;
- health-check и автоматическая проверка синтаксиса в GitHub Actions.

## Архитектура

- `index.html`, `styles.css`, `app.js` — интерфейс приложения;
- `api/profile.php` — загрузка, сохранение и удаление профиля;
- `api/event.php` — сохранение и пересылка событий;
- `api/health.php` — проверка готовности сервера;
- `api/bootstrap.php` — проверка Telegram-подписи и слой хранения;
- `api/config.example.php` — пример серверной конфигурации;
- `api/storage/` — защищённое локальное хранилище, если PDO/SQLite недоступен.

Хранилище работает в режиме `auto`:

1. использует PDO/SQLite, если расширение доступно;
2. иначе автоматически переходит на защищённые JSON-файлы.

Для первого запуска на REG.RU отдельную базу данных создавать необязательно.

## Обязательная настройка на сервере

1. Скопируйте `api/config.example.php` в `api/config.local.php`.
2. Вставьте токен бота из `@BotFather` в `bot_token`.
3. Проверьте адрес:

```php
'allowed_origin' => 'https://app.cmgroup.pro',
```

4. Убедитесь, что PHP может записывать в `api/storage`.
5. Откройте:

```text
https://app.cmgroup.pro/api/health.php
```

Рабочий ответ должен содержать:

```json
{
  "ok": true,
  "storage_ok": true,
  "bot_configured": true
}
```

Реальный `config.local.php`, токен бота и файлы профилей исключены из Git через `.gitignore`.

## Важное требование к запуску из Telegram

Для серверного профиля приложение должно открываться способом, при котором Telegram передаёт `initData` с пользователем:

- inline-кнопка Web App под сообщением;
- Menu Button;
- Main Mini App;
- прямая ссылка Mini App.

Не используйте обычную reply-клавиатуру как единственный способ запуска. `Telegram.WebApp.sendData()` доступен только для reply-кнопки и закрывает Mini App после отправки, а такой режим не подходит для постоянного личного кабинета.

## SaleBot / CRM

События уже сохраняются на сервере. Для автоматической передачи в SaleBot или CRM заполните в `api/config.local.php`:

```php
'event_webhook_url' => 'https://адрес-webhook',
'event_webhook_secret' => 'случайная_секретная_строка',
```

До добавления URL события не теряются: они остаются в локальном журнале сервера.

## Локальная проверка

```bash
node --check app.js
find api -name '*.php' -print0 | xargs -0 -n1 php -l
```

В обычном браузере интерфейс работает в локальном режиме. Серверная авторизация и синхронизация проверяются только при запуске из Telegram.
